# PRG120V – Obligatorisk oppgave 1

Obligatorisk innleveringsoppgave i programmering.

Oppgaven er laget med HTML, PHP og MySQL.

Applikasjonen inneholder funksjoner for å:
- Registrere klasser og studenter
- Vise alle klasser og studenter
- Slette klasser og studenter

Databasen administreres gjennom phpMyAdmin,
og nettsiden kjøres på Dokploy.
